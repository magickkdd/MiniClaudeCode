第一步：在当前目录写 calculator.py：实现 add、sub、mul、div 四个函数，div 遇到除数为 0 时抛 ValueError。

```python
def add(x, y):
    """Add x and y."""
    return x + y

def sub(x, y):
    """Subtract x from y."""
    return x - y

def mul(x, y):
    """Multiply x and y."""
    return x * y

def div(x, y):
    """Divide x by y."""
    if y == 0:
        raise ValueError("Division by zero is not allowed.")
    return x / y
```
